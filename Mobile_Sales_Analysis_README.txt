# Mobile-Sales-Analysis-Dashboard

The Mobile Sales Analysis Dashboard project uses Microsoft Power BI to explore mobile phone sales performance across cities, mobile models, and payment methods. The interactive dashboard brings key sales indicators and visual summaries together to help users understand sales distribution, compare quantities across locations, and examine customer payment preferences.

Strategic Goals & Features

Sales Performance Tracking: Monitor average sales, total sales, and total quantity through key performance indicators displayed at the top of the dashboard.

City-Wise Sales Analysis: Explore sales by city using a geographical map and compare total quantities across Mumbai, Raipur, Ranchi, and Delhi.

Mobile Model Performance: Use the model slicer to filter the dashboard and examine the quantity associated with different mobile models.

Payment Method Analysis: Compare total sales across Cash, UPI, EMI, and Card payment methods through an interactive pie chart.

Interactive Visualization: Bring KPI cards, maps, bar charts, and a pie chart together in one Power BI dashboard to support clear and convenient data exploration.

Tools Used

Microsoft Power BI: Dashboard development and data visualization.
Microsoft Excel: Source dataset used by the dashboard.
